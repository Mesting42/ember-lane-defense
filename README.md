# 边界航道：余烬防线

一款原创科幻策略塔防游戏。沿星域航路护送移民舰队，部署九类独立火力，跨越五段战区并击败最终旗舰。

## 启动

需要 Node.js 18 或更新版本。

```powershell
npm install
npm run dev
```

开发服务器启动后，打开终端显示的本地地址即可游玩。构建与预览生产版本：

```powershell
npm run build
npm run preview
```

## 游玩方式

1. 在星域地图选择当前航段的可用节点。普通战、精英战、补给、维修、事件和回收节点会改变舰队的资源与状态。
2. 战斗开始前从设施库选择设施，再点选空闲平台部署。九类设施都能独立攻击，部署后自动就绪，不需要反应堆、中继站或电量分配。
3. 手动启动第一波后，敌群会沿航道向舰队核心推进。清场后显示下一波来袭提示，3 秒后自动出敌，期间可继续建造和升级；战斗结束后选择战术模块。
4. 使用轨道轰击、全域冻结、核心护盾和维修蜂群应对危险波次。跨越五段战区后迎战三阶段旗舰。

支持鼠标和触屏点按。手机与平板可纵向滚动战场界面；星域地图在窄屏上可横向滚动。

针蜂、轨矛、弧光、彗星、冷凝、巡游蜂巢、脉冲哨塔、护盾冲击塔和诱导震荡塔均有各自的开火与命中反馈，包括弹道、光束、电弧、尾迹和对应音效。系统设置中的“音效”控制攻击音量；“简化战场动效”减少光晕和粒子，同时保留弹道、命中和危险预警。

### 键盘操作

| 按键 | 操作 |
| --- | --- |
| 空格 / P | 暂停或继续战斗与续波倒计时；首次部署启动第一波 |
| 1 / 2 / 3 | 切换 1×、2×、3×速度 |
| Q / W / E / R / T / Y / U / I / O | 选择九类设施 |
| Z / X / C / V | 轨道轰击、全域冻结、核心护盾、维修蜂群 |
| Esc | 取消建造、技能瞄准或设施选中 |

航路、战场、资源、研究记录和设置会自动保存在当前浏览器的本地存储中。刷新页面后，正在进行的战场会以暂停状态恢复。

## 防御设施素材

九类设施采用 Zsky 的 Low Poly Sci Fi Turrets 三维模型，统一制作灰蓝金属装甲、冷青能源和暖铜细节。游戏实际加载独立底座、32 方向炮头图集与设施图标，枪口闪光、弹道和光束使用同一份模型锚点数据。

原始模型使用 CC BY 4.0 许可；作者、来源、许可及修改说明见游戏内“素材鸣谢”和 `THIRD_PARTY_ASSETS.md`。模型源文件、离线渲染与重新打包工具均保留在项目中，正式构建无需实时三维渲染。

八类敌方舰船采用 Kenney Space Kit（CC0），使用独立的 32 方向图集；敌群手册和来袭预警共用对应舰船图标。素材来源与修改记录同样列在“素材鸣谢”。

## 响应式复核

### 浏览器三端与手机方向（2026-10-21）

手机正式作战推荐横屏：战场与技能保留在左侧，设施库、升级、暂停、倍速和启动控制位于右侧，设施列表独立滚动。横屏适配用于宽度不超过 1100、高度不超过 600 的横向窗口；不会强制锁屏或要求全屏。

竖屏可继续游戏：战场优先显示，设施与状态区向下排列。菜单、航路选择、设置和训练适合竖向阅读；切换手机方向会自动暂停战斗或演练，需手动继续。加入安全区留白、较大的触控按钮和小屏建筑名称，并为手指点击平台增加容错。

本版已在真实内置 Chromium 浏览器检查 13 种页面 × 12 种视口，共 156 个组合；覆盖 2560×1440、1440×900、平板双向，以及常见 iPhone／安卓尺寸的横竖屏。修复手机横屏设施库落到下方、控件过小，以及 667／740 宽奖励卡片裁切。最终未发现页面横向溢出，详见 `art-source/verification/browser-responsive-2026-10-21.json`。

浏览器实操完成横屏部署、升级、第一波启动、倍速和旋转暂停，及竖屏训练部署。后续检查使用 `tools/responsive-preview.html` 的独立场景和独立存档；该开发入口不进入正式 `dist/`。这属于 Chromium 视口验证，不等同于 iOS Safari／安卓真机、刘海安全区和实际触屏硬件测试。

### 大屏界面尺度（2026-10-19）

主菜单、航路、战场、奖励、商店、事件、维修、补给、设置、操作手册、训练和结算共用可缩放尺寸体系。浏览器保持 100% 即可：默认字体设置下，1280 CSS 像素宽及以下保持原尺寸，1920 宽约为原来 1.5 倍，2560 宽约为 2 倍，超大屏上限为 2 倍。使用实际 CSS 视口计算，不按设备像素比再放大，也不设置浏览器缩放。

文字、按钮、间距、图标、内容宽度上限和航路节点随全局 rem 尺度变化；手机和平板保留原有布局断点。桌面窗口较矮或使用超宽屏时，战场页面允许纵向滚动，设施库独立滚动。Canvas 继续按实际显示尺寸生成高清画布，部署坐标不变。

若之前为此游戏手动设置过 200% 浏览器缩放，请先用 Ctrl + 0 恢复 100%，再查看新布局。测试命令增加 `tools/test-layout.mjs`，检查 14 种视口宽度下的尺寸计算与断点；真实浏览器复核范围见 `QA_REPORT.md`。

基础界面此前已在浏览器视口复核桌面 1440 × 900、平板 820 × 1180、手机 390 × 844，均无页面横向溢出。战场沙盘保持 5:3 比例，窄屏下设施与指令区改为纵向浏览，路线图保留独立横向滚动。

当前版本已检查防御设施 288 帧图集、320 个枪口锚点、敌军 256 帧图集与三张战场离线画面，并测试三种战场缩放下的点按坐标。实际浏览器操作被工具安全机制中止（无法可靠识别 Windows 当前浏览器网址），本轮尚未完成实时浏览器三端排版和实际扬声器试听。

## 功能回归

```powershell
npm test
npm run build
```

测试包含真实引擎的独立武器检查、12 次普通资源战役模拟、隔离 DOM 环境中的 React 交互，以及 native canvas 画面检查。测试不访问玩家浏览器或本地存档。详情和范围见 `QA_REPORT.md`；原始记录位于 `art-source/verification/`。

建筑详情会显示装填、射程、受干扰或损毁等状态。原电力中继改为脉冲哨塔；护盾冲击塔和诱导震荡塔基础形态即有范围攻击，护盾与牵制作为额外能力保留。旧存档加载时自动按新规则启用，无需重开战役。

普通战后会回收存活设施投入的 60%、损毁设施投入的 25%（含升级）；结果计入结算页。后续战区有递增的最低战备补给，最终旗舰战最低 360 合金。旗舰突防会导致失败。

## 新手训练营

主菜单“新手训练营”或操作手册“进入实操训练营”可打开独立训练场。共 14 课，覆盖独立部署、针蜂射击与升级、脉冲哨塔，以及轨矛、弧光、彗星、冷凝、巡游蜂巢、护盾冲击塔、诱导震荡塔及其 B 路线强化。

每课有明确目标、目标平台标记、用途与搭配说明。调用正式引擎，在真实的开火、命中、减速、维修、恢复护盾或诱导出现后才判定完成。战斗示范至少显示 3.5 秒后暂停，便于观察。

支持课程回看、重试、跳过、退出与从头重新训练。小屏可使用平台快捷按钮完成部署。训练在 `ember-lane-training-v2` 单独保存课程进度，正式战役存档不受影响。旧的接电课程记录保留在旧键中，新课程从头开始。

## 独立攻击规则

- 任意空闲平台都可直接部署，不再显示供电范围、连线、电量预算或未接电提示。
- 脉冲哨塔发射独立能量光束；护盾冲击塔造成范围冲击并恢复核心护盾；诱导震荡塔基础形态就会攻击并短暂牵制敌人。
- 原供电商店和维修强化改为火控校准，提升全部建筑射速，不再销售电力。
- 旧存档保留资源、建筑和专精，原有中继直接转为脉冲哨塔。旧的供电字段仅用于读取兼容，不作为作战条件。

## 高清显示

- 新配置默认“高清”；设置 → 画面质量可在“高清”和“流畅”之间切换，已保存的选择继续保留。
- 高清画布随战场实际显示宽度、设备像素比、窗口大小及浏览器缩放调整。最低 1.5 倍采样，设备像素比最高按 3 倍处理，画布宽度上限 4096；流畅模式最高 1600 宽，降低绘制开销。
- 九类防御设施与八类敌军都提供独立高清图集，每方向 384 × 384 像素；流畅模式采用原 192 × 192 图集。高清素材从原始 384 像素渲染结果打包，不放大低清素材。
- 游戏逻辑与点按坐标仍为 1000 × 600，不影响射程、部署、枪口位置或存档。训练场共用同一显示逻辑。
- 桌面侧栏加宽，并增大建筑名称、资源、状态及升级说明文字。

## 自动续波

首次进入每个战场仍可自由部署，手动启动第一波。后续波次在清场后自动衔接：显示“第 X 波敌人来袭”和 3 秒倒计时，结束后出敌。倒计时期间可正常建造、升级和使用战术指令，2×、3× 速度保留实际 3 秒准备时间。

暂停、切换标签、进入设置或返回菜单会暂停倒计时；刷新后以暂停状态恢复剩余时间。旧存档停在波次间时，从 3 秒准备时间开始。最后一波按原流程结算，不会继续生成敌人。

## 战术模块徽章

奖励页主图标与 8 种模块统一使用立体金属徽章：灰蓝装甲、冷青能源、暖铜结构，每种模块有独立的识别图案。图标按模块 ID 绑定，随机奖励换序也保持对应；手机端使用更大的图标栏。

游戏素材位于 `public/assets/modules/`，为每张 384 × 384 的透明 WebP；整套约 436 KiB，页面只加载当前出现的徽章。ImageGen 生成的高清原图、完整提示词、预览和打包记录保留在 `art-source/module-badges/`，工具为 `tools/pack-module-badges.py`。
